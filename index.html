LLM forecasting: NFT hold-time analysis

Analyzed how long Bored Ape Yacht Club NFTs get held, using on-chain Ethereum data. Deployed a subgraph with The Graph to index 170,000+ transfer events, built a Python pipeline that labels wallets as flippers, swing traders, or collectors, and used LLMs to forecast short-term market behavior. Of the wallet addresses analyzed, 68.37% were classified as collectors, whose average hold time was 134.7 days. Team project; I set up the GraphQL queries, ran the LLM analysis, and wrote parts of the paper.

find-quasi-ids: a privacy tool for public datasets

With a teammate, audited an anonymized government student financial aid dataset for quasi-identifiers, and wrote a Python command-line tool to find them in other datasets. Found that three attributes were enough to uniquely single out 57.02% of records in the analyzed dataset; generalizing income lowered that to 48.46%. This measures uniqueness, not identification of named people.

Python · Columbia private systems course, Spring 2025 · Code
